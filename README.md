# WSP Bot — código

Exportación del código local al 13 de octubre de 2026. Incluye supervisor, eventos, envío, voz, utilidades, pruebas y modificaciones del bridge y servidor MCP de WhatsApp.

Los identificadores numéricos de contactos se sustituyeron por ejemplos. Configura `WSP_JID` antes de usarlo. No se distribuyen conversaciones, memoria personal, perfiles, audios de referencia, sesiones de WhatsApp, bases de datos, credenciales ni instrucciones con contenido privado.

Los scripts conservan la estructura local de `WSP Bot` y algunas rutas de esa instalación. Esta publicación es una copia del código existente y requiere preparar configuración, directorios de estado y dependencias para ejecutarla en otra máquina. No implica una instalación autónoma.

El bridge y el servidor MCP derivan de [whatsapp-mcp](https://github.com/lharries/whatsapp-mcp).

`archivo/` conserva otras dos variantes locales de código, incluida la extensión para perfiles de amigos.
